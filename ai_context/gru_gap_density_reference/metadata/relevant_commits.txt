dbcec8275983d0624db5d12de7bad8e770345c2c
added ground truth density calculation. What it does is takes the number of raw gap points detected by the robot within the sector, but uses the ground truth velocity of the agent to count the number of dynamic obstacles within the sector. This is different, obviously, than the data that's coming into the model, which estimates that velocity using a Kalman filter, or maybe I can use learning in the future, but yeah. The way the ground truth velocity for each agent is found is just like I did in the past for the velocity training stuff. I just find the nearest agent to the gap point, and if they're close enough, then I just take that agent's velocity and assign it to the gap point as the ground truth velocity. As a summary, that ground truth velocity is then attached to a raw gap point, and all of, and you know, this ground truth information and the gap point information is then used to calculate the ground truth density.
